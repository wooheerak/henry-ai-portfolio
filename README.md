# Henry AI Portfolio

Production-oriented portfolio for Henry Woo's transition from enterprise software engineering to AI Systems & Agent Engineering.

## Stack

- Next.js App Router
- TypeScript
- CSS without a UI framework
- Vercel-ready metadata, robots and sitemap

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run build
```

## Branch

Development work for the first evidence-driven redesign lives in `feature/ai-career-portfolio-v1`.

## Content policy

- Shipped work is separated from planned work.
- Metrics remain unpublished until they are measured.
- Client-sensitive details are sanitized.
- Every completed capability should link to code, tests, evaluation or a demo.
